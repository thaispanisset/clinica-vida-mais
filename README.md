# Clínica Vida+ — Exercícios de Programação

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, utilizando um cenário fictício de gestão de uma clínica de saúde.

## Objetivo

Aplicar conceitos de programação, estruturas de dados e algoritmos por meio de exercícios relacionados ao gerenciamento de pacientes e ao atendimento em uma clínica.

## Tecnologias utilizadas

- Python
- Visualg (Portugol)

## Exercícios desenvolvidos

### 1. Cadastro de pacientes — Python

Programa com menu interativo que permite:

- Cadastrar pacientes.
- Consultar estatísticas dos pacientes cadastrados.
- Buscar pacientes pelo nome.
- Listar os pacientes registrados.

Conceitos utilizados: listas, dicionários, estruturas condicionais, estruturas de repetição e tratamento de exceções.

### 2. Gerenciamento de fila — Visualg

Algoritmo que simula o gerenciamento de uma fila de atendimento, permitindo:

- Inserir três pacientes na fila.
- Chamar o primeiro paciente para atendimento.
- Exibir os pacientes que permanecem na fila.

Conceito utilizado: estrutura de dados FIFO (First In, First Out).

## Estrutura do repositório

- `python/`: código-fonte do programa em Python.
- `algoritmos/`: algoritmo desenvolvido no Visualg.

## Observação

Projeto acadêmico de caráter didático. Os dados utilizados nos exemplos são fictícios e o sistema não representa uma aplicação de gestão clínica em produção.
